# Images

Drop painting variant images into this folder, then add them to `paintings.js` (one level up).

**Naming convention:** `<painting-slug>-<variant-number>.<ext>`

Examples:

    mona-lisa-1.png
    mona-lisa-2.png
    starry-night-1.png

Use `tools/coordinate-picker.html` to grab Pikachu's box coordinates from each image, then paste them into `paintings.js`.
