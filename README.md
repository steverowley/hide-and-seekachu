# hide-and-seekachu

A "Where's Waldo"-style web game where Pikachu is hidden in famous public-domain paintings, restyled to blend into each artwork. Built as a personal project.

## Files in this folder

- [`PROJECT_PLAN.md`](./PROJECT_PLAN.md) — the high-level plan: concept, scope, tech approach, and how the work splits between me and Claude Code.
- [`BRIEF.md`](./BRIEF.md) — the prompt to paste as the first message to Claude Code. It builds the whole game from this.

## How to use

1. Install [Claude Code](https://docs.claude.com).
2. Open a terminal in this folder and run `claude`.
3. Paste the contents of `BRIEF.md` as the first message.
4. Once Claude has scaffolded the game, follow the steps in `PROJECT_PLAN.md` to generate painting variants and drop them in.
